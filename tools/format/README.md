# Curio Formatter (`tools/format`)

> Data transformation toolchain that compiles the rich curiosity dataset (`curiosities.json`) into the client-side database (`data.js`) for the Curiosity Planner web application.

---

## 1. Overview

The web client (`index.html`, `app.js`, `planner.js`) operates offline with zero external runtime dependencies. To minimize memory footprint and execution overhead, the web app does not need full wiki metadata (e.g. ingredient lists or raw MathML expressions).

The `tools/format` directory provides:
1. **Master Dataset (`curiosities.json`)**: Complete, structured curiosity metadata (847 items) produced by `tools/dump`.
2. **Compiler Script (`data_from_json.py`)**: A lightweight Python utility that extracts only simulation-relevant properties and exports them as `const CURIOSITIES_DATA = [...]` into `data.js`.

## 3. Schema Transformation Pipeline

`data_from_json.py` flattens and normalizes fields from `curiosities.json` to the client app format:

| Master Field (`curiosities.json`) | Target Field (`data.js`) | Type | Purpose |
|---|---|---|---|
| `name` | `name` | `string` | Unique curiosity name or variant label |
| `image` | `image` | `string` | URL to Ring of Brodgar image asset |
| `url` | `url` | `string` | Ring of Brodgar wiki page URL |
| `baseLP` | `points` | `number` | Base Learning Points (at Q10) |
| `mentalWeight` | `weight` | `number` | Attention / Mental Weight cost |
| `expCost` | `xpCost` | `number` | Experience Points consumed on study completion |
| `studySeconds` | `studySeconds` | `number` | Real-time study duration in seconds |
| `size.width` | `w` | `number` | Horizontal grid cells occupied |
| `size.height` | `h` | `number` | Vertical grid cells occupied |
| `requirements.producer.name` | `producer` | `string \| null` | Crafting station (e.g. "Anvil", "Hand") |
| `requirements.skills[].name` | `skills` | `string[]` | Associated skills (e.g. `["Hunting"]`) |

### Example Input (`tools/format/curiosities.json`)
```json
{
  "name": "Uncommon Snapdragon",
  "image": "https://ringofbrodgar.com/wiki/File:Uncommon_Snapdragon.png",
  "url": "https://ringofbrodgar.com/wiki/Uncommon_Snapdragon",
  "baseLP": 1000,
  "mentalWeight": 4,

    "width": 1,

  }

```

## 4. Usage & Regeneration Commands

### Compiling `curiosities.json` into Root `data.js`
To update the project's static database after editing `curiosities.json` or running a wiki scrape:

```powershell
python tools/format/data_from_json.py -i tools/format/curiosities.json -o data.js
```

### CLI Arguments Reference

| Argument | Required | Default | Description |
|---|---|---|---|
| `-i` | No | `tools/format/curiosities.json` | Path to source JSON file. |
| `-o` | No | `tools/format/data.js` | Destination JavaScript file. Specify project root `data.js` to update the application. |

## 5. Invariants & Guidelines for AI Developers

1. **Never Edit `data.js` Manually**: `data.js` is an auto-generated build artifact. All data adjustments must be made in `tools/format/curiosities.json` (or via `tools/dump` crawler patches), followed by re-running `data_from_json.py`.
2. **Strict UTF-8 Encoding**: Both input and output files must be encoded in UTF-8 without BOM. Special characters and accents (e.g. `Völva's Wand`) must be properly preserved.
3. **Item Count Verification**: The catalog currently contains **847 items** (540 gemstones + 307 standard and multi-variant curiosities). After regeneration, verify that `node -e "const fs=require('fs'); const vm=require('vm'); vm.runInThisContext(fs.readFileSync('./data.js', 'utf8')); console.log(CURIOSITIES_DATA.length);"` outputs `847`.
4. **Zero Runtime Dependency**: Keep `data.js` purely as a browser-compatible script defining `const CURIOSITIES_DATA = [...]`. Do not use ES module `export` or Node.js `module.exports` syntax in `data.js`, as it is loaded via a standard `<script src="data.js">` tag in `index.html`.
